Keyboard shortcuts

  • cNew ticket (not on the ticket page)
  • g then tTickets
  • g then aArchive
  • g then rRepositories
  • jkEnterMove through and open tickets (ticket lists)
  • s then 1Needs Input: Stop, Back to Needs Input or Reopen (ticket page, when shown)
  • s then 2Send to QA (ticket page, when shown)
  • s then 3Done (ticket page, when shown)
  • Ctrl+/Next ticket in Needs Input (any page)
  • Ctrl+EnterSend reply (reply box) or start the ticket (editor)
  • Ctrl+KPick repository (editor)
  • ?Show this help
  • EscClose
